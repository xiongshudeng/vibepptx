# VibePPTX
面向教研、技术分享与初创路演的 AI PPT 生成工具

🔗 官网：https://www.vibepptx.com

> 输入 Markdown 教案、README 文档或者路演提纲，docx资料，PDF论文，excel数据，epub电子档一键生成原生可编辑 PPTX。专门针对中文排版优化，自动分页，减少文字溢出问题。
> 单独上传 PPT可以美化，也可以当作其他资料都参考模板
> 支持多个文件上传
## ✨ 核心特性
- ✅ 输出原生 `.pptx` 文件，WPS / PowerPoint 可直接二次编辑，不是图片幻灯片，所有的形状，文字，文本框，图片，图层，所有元素都可以二次编辑
- ✅ 中文长文本智能分页、智能排版，自适应字号，解决通用AI工具中文排版溢出痛点
- ✅ 内置64套模板，涵盖学术答辩，企业数智化，科技数据，麦肯锡商务，美食文化，政务，医疗卫生，传统文化，企业运营，教育，各种模板
- ✅ 提供海量PPT模板资源下载
- ✅ 支持企业模板，个人专属模板固化，长期复用
- ✅ 支持单次上传自己的模板，仅单次有效
- ✅ 长文档离线任务队列，用户只需上传文档，输入提示词，启动任务后，就无需关心任务何时完成，任务完成后PPT文字自动出现左侧文件栏，一次任务十几到二十几分钟
- ✅ 价格便宜，每天签到有免费额度，免费额度用完后每份只需2元RMB，比市面上其他家都便宜。不采用AI生图模型，尽量使用原图及AI自行绘制图标，网络智能搜索匹配的图片，避免PPT AI味太重，token消耗极低

## 🎯 适合人群
- 教研老师：快速把教案转为课堂课件,把PDF试卷转成能讲解的PPT
- 学生：把自己的中文作文，英文作文，入党申请书，入团申请书，考试试卷，大学生毕业论文都可以转成PPT，甚至，只需输入一个主题，AI自动调研，生成大纲，自动排版，生成PPT
- 公司员工：宣传报告，销售报告，数据总结，AI自动排版，自动统计，生成PPT
- 创业者：快速搭建标准化融资路演PPT框架

## ❓ 常见问题
### 生成的PPT是图片吗？
不是。输出原生PPTX，所有文本都是独立文本框，图片，图标，文字，下载后可以自由修改内容、配色和版式。

### 对中文排版友好吗？
内置中文断行与自适应排版逻辑，区别于优先英文的通用AI PPT工具，降低文字挤压、溢出。

### 支持哪些输入格式？
现阶段支持 Markdown,docx,pdf,pptx,txt 为主，适合结构化提纲、教案、技术文档,论文，学生作业。
